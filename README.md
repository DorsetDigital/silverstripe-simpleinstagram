# silverstripe-simpleinstagram

> **Archived / no longer maintained**
>
> This module relied on an unofficial Instagram feed integration. Changes to Instagram/Meta's APIs and access controls made that approach unreliable, and the module is no longer maintained.
>
> Existing users should replace it with an integration based on Meta's currently supported APIs. No further development is planned for this package.

---

This module retrieved an Instagram feed for a given user for embedding in a Silverstripe template. The code remains available for existing users and historical reference.
